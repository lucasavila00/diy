# @beff/diy-cli

Command-line analyzer for DIY dependency injection projects.

This package contains the publishable `diy-cli` binary. It analyzes TypeScript source files using a `diy.json` project file and reports DIY capability lint issues, unused capabilities, redundant providers, and optional module graph output.

For full documentation, examples, and runtime package usage, see the GitHub repository:

https://github.com/lucasavila00/diy
