# @beff/diy

TypeScript runtime helpers for DIY dependency injection.

This package contains the public `Capability` and `Capabilities` types plus helper functions for creating, merging, extending, and overriding capability objects. It has no runtime dependency injection container, reflection, metadata scanning, or graph solving.

For full documentation, examples, and CLI usage, see the GitHub repository:

https://github.com/lucasavila00/diy
